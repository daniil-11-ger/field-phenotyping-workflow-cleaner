# Интерактивное приложение для workflow кунжута

## Что добавлено

В проект добавлено интерактивное приложение на R Shiny:

```text
shiny_app/
├── app.R
├── packages.R
└── www/
    └── app.css
```

Приложение превращает технический pipeline в веб-интерфейс: пользователь загружает CSV из Field Book, нажимает **Run workflow**, после чего получает интерактивные таблицы, графики, карту поля, журнал выбросов и файл очищенных данных.

## Основные разделы приложения

1. **Data upload** — загрузка CSV или запуск демо-данных.
2. **QC summary** — количество записей, растений, признаков и отмеченных ошибок.
3. **Outliers** — интерактивная проверка выбросов по признакам.
4. **Spatial view** — карта поля по row/column с выбранным признаком.
5. **Breeding model** — демонстрационная LMM/BLUP-модель `trait ~ block + (1 | entry)`.
6. **DNA extraction** — сравнение CTAB-PK и Qiagen Genomics-Tip.
7. **About** — описание назначения приложения.

## Как открыть локально

1. Открыть проект в RStudio.
2. Установить пакеты:

```r
source("shiny_app/packages.R")
```

3. Запустить приложение:

```r
shiny::runApp("shiny_app")
```

После этого приложение откроется в браузере.

## Как загрузить на shinyapps.io

1. Создать аккаунт на shinyapps.io.
2. В RStudio установить пакет:

```r
install.packages("rsconnect")
```

3. В личном кабинете shinyapps.io скопировать команду `rsconnect::setAccountInfo(...)`.
4. Запустить:

```r
source("deploy/shinyapps_publish.R")
```

После публикации будет создана веб-ссылка, которую можно вставить в статью, презентацию или приложение к отчету.

## Как запустить через Docker

Если нужен современный воспроизводимый запуск на сервере:

```bash
bash deploy/docker_run.sh
```

После запуска открыть в браузере:

```text
http://localhost:3838
```

## Что можно показать в статье

В разделе технического приложения можно написать:

> Для повышения доступности разработанного workflow был создан интерактивный веб-интерфейс на базе R Shiny. Приложение позволяет загружать экспортированные CSV-файлы Field Book, выполнять автоматическую очистку данных, выявление выбросов, визуализацию распределений признаков, пространственный анализ по координатам поля и формирование очищенного датасета для последующего селекционного моделирования. Приложение может быть запущено локально, опубликовано на shinyapps.io или развернуто в Docker-контейнере.

## Какие файлы нужны для публикации

Для публикации приложения достаточно папки `shiny_app`, а также папок `data/raw` и `metadata`, если нужно оставить демо-данные и биологические пороги внутри приложения.
