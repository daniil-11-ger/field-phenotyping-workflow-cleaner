# Описание кода для раздела «Материалы и методы»

Для обеспечения воспроизводимости анализа был разработан набор R-скриптов, реализующих полный цикл обработки полевых фенотипических данных. Скрипт `00_config.R` содержит настройки проекта, список необходимых пакетов, пути к папкам и биологически допустимые диапазоны значений признаков. Скрипт `01_import_fieldbook.R` выполняет импорт и объединение CSV-файлов, экспортированных из Field Book. Скрипт `02_clean_transform.R` стандартизирует названия признаков, приводит значения к числовому формату, удаляет дубликаты и преобразует данные из длинного формата в широкий.

Контроль качества выполняется скриптом `03_quality_control.R`, который рассчитывает долю пропущенных значений, наличие дублирующихся идентификаторов и основные описательные статистики. Скрипт `04_outlier_detection.R` реализует выявление выбросов на основе биологических порогов и метода межквартильного размаха. Все исключенные значения сохраняются в отдельном журнале, что обеспечивает прозрачность процедуры фильтрации. Скрипт `05_mixed_models.R` формирует предварительные линейные смешанные модели с учетом блока и генотипа, а также сохраняет компоненты дисперсии и BLUP-оценки. Дополнительно скрипт `06_dna_extraction_summary.R` формирует таблицы и графики сравнения методов экстракции высокомолекулярной ДНК.

Весь анализ запускается единым управляющим скриптом `run_all.R`, что позволяет воспроизвести обработку данных при поступлении новых полевых измерений без ручного повторения отдельных этапов.
